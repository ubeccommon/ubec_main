DATA FLOW: Stellar Network → Phenomena → Intentional Relations → 
           Temporal/Spatial/Holonic Analysis → Insights

UBUNTU MAPPING:
    🜁 Air (UBEC)      = Diversity      → Universal access, variety
    🜄 Water (UBECrc)  = Reciprocity    → Flow, exchange, balance
    🜃 Earth (UBECgpi) = Mutualism      → Stability, relationships
    🜂 Fire (UBECtt)   = Regeneration   → Transformation, growth

PHENOMENOLOGICAL PRINCIPLES:
    1. Intentionality: All relations are directedness toward objects
    2. Horizons: Internal (properties) + External (context)
    3. Temporality: Retention (past) + Present + Protention (future)
    4. Spatiality: Network has geometric structure
    5. Holonomy: Nested wholes with autonomy + integration

SPATIAL CAPABILITIES (PostGIS):
    ✓ Network embeddings in 2D/3D space
    ✓ DBSCAN clustering for communities
    ✓ Voronoi territories
    ✓ Convex hulls of holder groups
    ✓ Geodesic pathfinding
    ✓ Distance queries (meters in network space)
    ✓ Spatial indexes (GIST) for fast queries

TEMPORAL CAPABILITIES:
    ✓ Automatic retention creation on updates
    ✓ Configurable memory fading (retention_clarity)
    ✓ Protention tracking with confidence scores
    ✓ Fulfillment analysis (predicted vs actual)
    ✓ Temporal consciousness stream view

TECHNOLOGY STACK:
    • PostgreSQL 15+ (Database)
    • PostGIS 3+ (Spatial extensions)
    • asyncpg (Async Python driver)
    • Python 3.10+ (Application layer)

## Key Relationships

```
ASSETS (1) ←──────── (N) INTENTIONAL_RELATIONS (N) ──────────► (1) ACCOUNTS
                              │
                              ├──► RETENTIONS (History)
                              ├──► PROTENTIONS (Predictions)
                              └──► SPATIAL_POSITIONS (Topology)

ACCOUNTS (N) ←──────── (N) HOLONS (Nested Communities)
                              │
                              └──► SPATIAL_REGION (Geographic extent)

SPATIAL_POSITIONS (N) ──────► (1) NETWORK_EMBEDDINGS (Version control)

INTENTIONAL_RELATIONS (N) ──► (N) GEODESICS (Computed paths)
```

## Sample Queries by Layer

### Phenomenal Layer
```sql
-- Get all assets in ready-to-hand mode
SELECT * FROM phenomenal.assets 
WHERE existence_mode = 'ready_to_hand';
```

### Intentional Layer
```sql
-- Find strongest trustlines
SELECT * FROM phenomenal.intentional_network
WHERE relation_type = 'trustline'
ORDER BY relation_strength DESC;
```

### Temporal Layer
```sql
-- View temporal stream for an asset
SELECT * FROM phenomenal.temporal_consciousness
WHERE entity_type = 'asset' AND entity_id = 1;
```

### Spatial Layer
```sql
-- Find accounts within 5km of an asset
SELECT account_address, distance_km
FROM phenomenal.accounts a, phenomenal.assets ast
WHERE ast.asset_code = 'UBEC'
  AND ST_DWithin(a.network_position::geography, 
                 ast.network_position::geography, 5000)
ORDER BY distance_km;
```

### Holonic Layer
```sql
-- Get highly integrated holons
SELECT * FROM phenomenal.holons
WHERE integration_score > 0.7
ORDER BY integration_score DESC;
```
