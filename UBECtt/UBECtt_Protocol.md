## Transformation Process

### Phase 1: Community Formation
**Requirements:**
- Minimum 50 verified members
- Geographic or purpose-based community
- Clear transformation goal
- Documented community agreement

### Phase 2: Proposal Creation
**Components:**
- Transformation vision (what will change)
- Resource allocation plan
- Success metrics
- Timeline (typically 6-24 months)
- Community commitment signatures

### Phase 3: Community Voting
**Process:**
```
Day 1-3: Proposal review & discussion
Day 4-7: Voting period
Day 8: Results & execution

Passing Threshold: 51% approval
Quorum Required: 50% of members
```

### Phase 4: UBEC Commitment
**Pooling:**
- Members commit UBEC to transformation
- UBEC locked in transformation contract
- Cannot be withdrawn during active transformation
- Released upon completion or cancellation

### Phase 5: UBECtt Distribution
**Multiplication:**
- System multiplies committed UBEC × 10
- UBECtt minted and distributed
- Proportional to individual contribution
- Voting power activated

### Phase 6: Transformation Execution
**Activities:**
- Deploy resources according to plan
- Community governance decisions
- Regular progress reporting
- Success metric tracking

### Phase 7: Completion
**Outcomes:**
- Final impact assessment
- UBEC returned to contributors
- UBECtt retained or converted
- Learnings documented & shared

## Governance Model: Keeper of the Fire

**Indigenous-Inspired Structure:**

**Keeper Circle** (9 members):
- 3 Elders (wisdom keepers)
- 3 Youth (future representatives)
- 3 Active Members (current work)

**Responsibilities:**
- Facilitate proposals
- Ensure fair process
- Protect community values
- Resolve conflicts
- Report to community

**Term:** 1 year rotating  
**Selection:** Community nomination & vote

**Decision Process:**
```
Minor Decisions (<10% resources):
  - Keeper Circle decides
  
Major Decisions (>10% resources):
  - Community vote required
  - 7-day deliberation
  - Simple majority
  
Emergency Decisions:
  - Keeper Circle emergency powers
  - Must report within 24 hours
  - Community can override
```

## Economic Architecture

### Token Supply Dynamics

**Minting:**
- Only through approved transformations
- 10:1 multiplier on locked UBEC
- Proportional distribution to participants

**Burning:**
- Voluntary conversion back to UBEC (1:8 ratio)
- Transformation completion return
- Inactive community dissolution

**Supply Formula:**
```
Total UBECtt = Sum of all active transformations × 10
```

### Value Preservation

**UBEC Backing:**
- Every 10 UBECtt backed by 1 locked UBEC
- 1:8 redemption ratio (20% community tax)
- 20% supports new community transformations

**Conversion Options:**

## Anti-Capture Mechanisms

### Prevents Wealthy Takeover

**Requirements:**
- Minimum community size (50 members)
- Maximum individual contribution (20%)
- One-member-one-vote (regardless of contribution)
- Democratic governance cannot be bypassed

**Example:**
```
Scenario: Wealthy individual tries to dominate

Wealthy person contributes: 50,000 UBEC (50% of pool)
49 others contribute: 50,000 UBEC (50% of pool)

Voting power:
Wealthy person: 1 vote (2%)
Others: 49 votes (98%)

Result: Community retains democratic control
```

### Sybil Resistance

**Identity Verification:**
- Stellar account age (90 days minimum)
- Minimum 10 UBEC holding
- Geographic verification
- Social attestations (3+ community members)
- Video verification calls

**Community Vetting:**
- New member proposals
- Existing member sponsorship
- Integration period
- Gradual voting power increase

## Integration Guidelines

### Creating Transformation

```python
from ubec_sdk import FireTokenProtocol

fire = FireTokenProtocol(community_keypair)

transformation = fire.propose_transformation(
    community_id="muellrose_solar",
    members_count=200,
    ubec_commitment=50000,
    transformation_goal="100% renewable energy",
    timeline_months=18,
    success_metrics=["kWh produced", "CO2 reduced"]
)
```

### Voting

```python
vote = fire.vote_on_transformation(
    transformation_id=transformation.id,
    vote=True,  # Yes/No
    rationale="Essential for our energy independence"
)
```

### Execution

```python
if transformation.status == "approved":
    result = fire.execute_transformation(
        transformation_id=transformation.id,
        issuer_keypair=issuer
    )
    # Locks UBEC, mints UBECtt, distributes
```
