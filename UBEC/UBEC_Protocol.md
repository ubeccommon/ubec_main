# 🜁 UBEC Protocol - Air Element: Gateway & Access

## Overview

**Element:** Air (🜁)  
**Token:** UBEC (Ubuntu Basic Economic Commons)  
**Role:** Gateway & Universal Access  
**Principle:** *Freedom of movement, accessibility, and universal participation*

The UBEC token serves as the gateway to the Ubuntu Economic Commons ecosystem. Like air, it is meant to be freely accessible to all, providing the fundamental medium through which participants can enter and move within the economic commons.

## Elemental Significance

Air represents:
- **Freedom**: Unhindered movement and transaction capability
- **Accessibility**: Universal access without barriers
- **Connection**: The medium through which all elements interact
- **Circulation**: Continuous flow throughout the ecosystem

## Usage Examples

### Basic Transaction
```python
from UBEC import UBECProtocol

# Initialize protocol
ubec = UBECProtocol()

# Check health
status = ubec.health_check()
print(f"UBEC Protocol Status: {status['gateway_active']}")

# Get token status
info = ubec.get_status()
print(f"Total Holders: {info['total_holders']}")
print(f"Accessibility Score: {info['accessibility_score']}")
```

### Holonic Evaluation
```python
# Evaluate an account's holonic alignment
account_id = "GXXXX..."
evaluation = ubec.evaluate_holonic(account_id)

print(f"Holonic Score: {evaluation['holonic_score']}")
print(f"Alignment Level: {evaluation['alignment_level']}")
print(f"Metrics: {evaluation['metrics']}")
```

### Sync with Blockchain
```python
# Synchronize protocol data
result = ubec.sync()
print(f"Sync Status: {result['sync_status']}")
print(f"Holders Synced: {result['holders_synced']}")
```
